# 費用 — 実測と見積り

**価格の最終更新: 2026-08-20**（モデル価格は変わるため、セットアップ時に Claude Code が [公式価格ページ](https://docs.claude.com/en/docs/about-claude/pricing) で最新を確認すること）

## 結論から

- **月100件のフォームなら、AI 費用は月数百円**（Sonnet で約 $1.8 ≒ 280円前後 / Haiku で約 $0.9 ≒ 140円前後。円換算は目安で為替により変動）
- インフラ費（Cloudflare / AWS）はこの流量帯では**誤差**（$0〜5/月）
- つまり総費用は事実上 AI API 費用だけで決まり、コスト最適化の優先順位は「インフラ選び」ではなく「モデル選択と出力トークン制御」にある

## AI API 費用（1 分類あたり）

前提: 入力 約3,800 トークン（判定基準プロンプト 2,000 + few-shot 例 1,500 + フォーム本文 300）、出力 約1,000 トークン（思考トークン込み）。

| モデル | 価格（$/MTok 入力/出力） | 1件あたり | 月100件 | 月1,000件 |
|---|---|---|---|---|
| claude-sonnet-5 | $2 / $10 | 約 $0.018 | 約 $1.8 | 約 $18 |
| claude-haiku-4-5 | $1 / $5 | 約 $0.009 | 約 $0.9 | 約 $9 |

- Sonnet 5 の $2/$10 は発表時「2026-08-31 までのイントロ価格」だったが、公式に恒久価格化された（$3/$15 への値上げは中止。[公式価格ページ](https://docs.claude.com/en/docs/about-claude/pricing)の注記参照）
- **モデルの選び方**: 月1,000件を超える、またはコスト最優先なら Haiku。判定の際どさ（協業提案とリードの区別等）が多い業種なら Sonnet を推奨
- 当社実測: 月平均約82件の AI 分類で Sonnet 換算 月約 $1.5 — 上の式と一致
- prompt caching はキャッシュ有効期間（5分）の都合上、月1万件以下の流量では恒常的な削減効果は見込めない（見積りに入れない）

## インフラ費用（月額）

| 構成 | 月額 | 内訳 |
|---|---|---|
| 経路A/B: Cloudflare Workers | **$0 〜 $5** | 無料枠（10万リクエスト/日・KV 書き込み1,000/日等）で概ね収まる。Paid プランは $5/月〜（最低額。含まれる枠を超えた分は従量課金だが、この流量帯では枠内） |
| 経路C: AWS（API GW + Lambda + SQS + Secrets Manager + CloudWatch） | **$0.40 〜 $3** | 無料枠適用後は Secrets Manager の $0.40 のみ。無料枠なしでも月 $2〜3。月1万件でもほぼ不変 |

## 費用の上限設定（必須 — 安全不変条件 7）

運用開始前に必ず設定する:

1. **Anthropic Console** → Settings → Limits で月間利用上限を設定（推奨: 想定月額の3〜5倍。例: 月100件想定なら $10〜15）
2. **Cloudflare**: Billing → 通知設定（Paid プランの場合）
3. **AWS**: AWS Budgets で月額アラート（例: $10）

上限に達すると分類は失敗するが、安全不変条件1（fail-open）により**フォーム受付は止まらず、全件が人間確認（REVIEW）に落ちるだけ**である。

## 見積りの計算式（Claude Code 用）

セットアップ時のインタビューで月間件数 N を聞いたら:

```
月額AI費用（Sonnet） ≒ N × $0.018
月額AI費用（Haiku）  ≒ N × $0.009
```

を即答し、上の表の最新価格で補正すること。
